소개 인적 학술 경력 아이디어
[기획서] 프로젝트 개요 & 방향성
  • 서비스명: 오늘 뭐 먹지? (결정장애 전용 메뉴 큐레이션 & 가이드)
  • 기획 배경: 매일 점심/저녁마다 "아무거나"를 외치며 10분 이상 고민하는 결정 피로를 해결
  • 핵심 타겟: 공강 시간 빠른 점심이 필요한 대학생, 자취생 혼밥러, 주변 밥집을 찾는 동기 모임
  • 개발 방향성: 복잡한 외부 서버나 무거운 프레임워크 없이, 순수 HTML5, CSS3 미디어 쿼리, 기초 JavaScript만으로 빠르고 가볍게 작동하는 반응형 웹 제작
[화면 설계] 5개 탭 콘텐츠 계획
  • 1. 가이드 소개 (mintro): 사이트 목적 및 3단계 결정 프로세스(카테고리 선택 → 예산 체크 → 메뉴 확정) 안내
  • 2. 메뉴 분류표 (minfo): 한식/중식/일식/양식/분식별 대표 메뉴, 평균 소요 비용, 추천 시간대 표(Table) 정리
  • 3. 상황별 큐레이션 (mstudy): 날씨(비/더위), 해장, 혼밥, 월급날/시험 끝난 날 특식 등 테마별 추천 리스트
  • 4. 꿀조합 & 절약팁 (mcareer): 프랜차이즈 실패 없는 시크릿 꿀조합(서브웨이 등) 및 배달비 절약 팁
  • 5. 기능 기획 & 로드맵 (midea): 초급/중급 단계별 기능 구현 계획 및 디바이스별 레이아웃 전략 기록
[기능 명세] 구현 가능한 실전 로드맵
  • [기초 구현] 원클릭 랜덤 메뉴 추첨 (JS Math.random)

    - 버튼 클릭 시 배열에 저장된 메뉴 중 1개를 무작위로 화면에 즉시 띄워주는 경량 기능

  • [기초 구현] 예산/상황별 단순 필터링

    - '만원 이하', '국물 요리', '초스피드 패스트푸드' 등 선택 버튼 클릭 시 해당 조건의 메뉴만 화면에 표시

  • [편의 기능] 네이버/카카오 지도 검색 원클릭 연동

    - 복잡한 지도 API 연동 대신, 당첨된 메뉴 이름을 검색어로 담은 지도 링크(`` 태그)로 바로 연결

  • [편의 기능] URL 복사 및 공유

    - 단톡방 친구들에게 추천 결과를 공유할 수 있도록 '현재 페이지 링크 복사' 클립보드 버튼 지원

[UI/UX] PC-모바일 반응형 설계
  • PC 환경 (기본 가로 너비): 메뉴 카드와 세부 정보표가 가로로 나란히 배치되는 여유로운 2단 레이아웃
  • 모바일 환경 (CSS 미디어 쿼리 768px 이하): 한 손 터치 스크롤에 맞춘 1열 수직 카드 스택 및 터치하기 쉬운 큰 버튼 적용
