기획서 📋

"오늘 뭐 먹지?"의 기획 의도와 화면 구성, 구현한 기능, 그리고 초기 기획에서 바뀐 점을 정리했어요.

1프로젝트 개요 & 방향성

  • 서비스명오늘 뭐 먹지? (결정장애를 위한 메뉴 추천 반응형 웹)
  • 기획 배경매일 점심·저녁마다 "아무거나"를 외치며 10분 이상 고민하는 결정 피로를 해결
  • 핵심 타겟공강 시간 빠른 점심이 필요한 대학생, 자취생 혼밥러, 주변 밥집을 찾는 동기 모임
  • 개발 방향성복잡한 외부 서버나 무거운 프레임워크 없이 순수 HTML5, CSS3 미디어 쿼리, JavaScript만으로 빠르고 가볍게 작동하는 반응형 웹 제작 (기록은 브라우저 localStorage에 저장, 날씨는 무료 API 사용)

2화면 설계 · 7개 탭 구성

  • 🎲 추첨종류·예산·상황 조건 선택 → 룰렛 추첨 → 결과 확정 (3단계 결정 프로세스), 상황별 테마 카드와 날씨 맞춤 추천
  • 🏆 월드컵둘 중 더 끌리는 메뉴를 고르는 토너먼트, 후보 수에 맞춰 4강/8강/16강 자동 대진
  • 🎡 돌림판단골집·메뉴·"누가 계산?"까지 후보를 직접 넣고 돌리는 원판
  • 📖 도감전체 메뉴 사진 카드, 검색·종류·가격 정렬, 즐겨찾기/안 먹는 메뉴 표시, 종류별 요약표(table)
  • 📝 기록결정한 메뉴 목록, 자주 먹은 메뉴 TOP 3, 종류별 막대 그래프
  • 💸 N빵같이 먹은 금액을 인원수대로 나누는 계산기
  • 📋 게시판맛집 추천·메뉴 고민·자유 말머리로 글과 댓글을 나누는 게시판 (검색, 페이지 번호, 추천, 내 글만 수정·삭제)

3기능 명세 · 구현한 기능

  • [기초] 원클릭 랜덤 메뉴 추첨버튼 클릭 시 배열에 저장된 메뉴(234개) 중 1개를 Math.random으로 뽑고, 이름이 빠르게 바뀌다 멈추는 룰렛 효과로 표시
  • [기초] 예산·상황별 필터링'~1만2천원', '#국물', '#빠름', '#여럿이' 등 선택 버튼을 누르면 조건을 모두 만족하는 메뉴만 후보로 사용
  • [편의] 지도 검색 연동복잡한 지도 API 대신 메뉴 이름을 검색어로 담은 지도 링크(<a> 태그)로 연결 + 내 위치·학교 근처(위성좌표) 검색
  • [편의] 결과 공유"오늘 메뉴는 김치찌개!" 같은 결과 문장을 문자(sms:)·메일(mailto:)·휴대폰 공유창·클립보드 복사로 전달
  • [추가] 개인화 & 기록즐겨찾기·안 먹는 메뉴 표시, 최근 3일 동안 먹은 메뉴 자동 제외, 먹은 기록과 통계 (localStorage 저장)
  • [추가] 날씨 맞춤 추천현재 위치(Geolocation) 또는 고른 지역의 날씨를 받아 비·눈이 오면 국물, 더우면 시원한 메뉴 추천
  • [추가] 배경음악 & 끊김 없는 탭 이동재생/정지 버튼, 탭을 옮겨도 음악이 끊기지 않도록 가운데 내용만 바꿔 끼우는 방식으로 이동
  • [추가] 드롭다운 하위 메뉴메뉴마다 ▾ 하위 메뉴를 두어 날씨 추천·종류별 도감·즐겨찾기 월드컵 같은 기능으로 바로 이동 (PC는 mouseover/mouseout 이벤트로 열고 닫음, 햄버거 메뉴는 ▾ 버튼으로 펼침)
  • [추가] 마우스 이벤트 & 대체 이미지테마 카드에 마우스를 올리면 이모지가 그 테마에 맞는 메뉴 사진으로 바뀌고, 사진을 못 불러오면(onerror) 메뉴 이모지로 대신 표시
  • [추가] 회원가입 & 로그인아이디 중복 확인·비밀번호 조건과 안전도·약관 동의가 있는 회원가입, 로그인 상태 유지와 보던 페이지로 돌아가기, 로그아웃·회원 탈퇴. 로그인하면 기록·즐겨찾기를 계정마다 따로 저장 (비밀번호는 암호화한 값만 보관)
  • [추가] 게시판글 목록(표, 폰에서는 카드), 말머리 필터와 검색, 페이지 번호, 글쓰기·수정·삭제(내 글만), 댓글, 추천, 조회수, 이전글·다음글. 글쓰기·댓글·추천은 로그인 필요

4UI/UX · PC-태블릿-모바일 반응형 설계

  • PC (1024px 이상)위쪽 가로 메뉴(마우스를 올리면 하위 메뉴), 조건 선택과 추첨 결과가 나란히 배치되는 2단 레이아웃, 도감 카드 4열
  • 태블릿 (768~1023px)☰ 햄버거 메뉴(2열로 펼침, ▾로 하위 메뉴), 1단 레이아웃, 도감 카드 3열
  • 모바일 (767px 이하)☰ 햄버거 메뉴(▾로 하위 메뉴), 한 손 터치 스크롤에 맞춘 1열 카드와 큰 버튼, 화면 아래 빠른 추첨 버튼, 도감 카드 2열

5초기 기획에서 바뀐 점

  • 가이드 소개 탭 → 첫 화면에서 바로 추첨설명을 읽는 것보다 바로 눌러 보는 것이 빠르다고 판단해 3단계 결정 과정을 첫 화면에 그대로 배치
  • 메뉴 분류표 → 사진 도감 + 종류별 요약표글자만 있는 표 대신 실제 음식 사진 카드로 바꾸고, 종류별 평균 가격 비교는 요약표로 유지
  • 상황별 큐레이션 탭 → 테마 카드·날씨 추천으로 통합탭을 옮기지 않고 "비 오는 날", "해장이 필요해" 등을 누르면 바로 조건이 적용되도록 변경
  • 꿀조합 & 절약팁 탭 제외 → N빵 계산기 추가읽을거리보다 실제로 쓰는 기능에 집중하고, 절약 관점은 같이 먹은 금액을 나누는 계산기로 보완
  • 링크 복사 → 결과 문장 공유페이지 링크만 보내면 친구에게 추천 결과가 전달되지 않아, 결과가 담긴 문장을 보내는 방식으로 변경
  • 월드컵·돌림판·기록 추가고르는 재미(월드컵·돌림판)와 실제 쓸모(기록·최근 먹은 메뉴 제외)를 더해 "고르기 → 기록 → 계산" 흐름 완성
